# 更新记录

## 0.3.0-r1

视觉细化，并在 ImmortalWrt 25.12（apk、LuCI 26.249）上验证。

- 采用 Apple 系统色板的浅色与深色变量；强调色、按钮、选中项和焦点环统一跟随外观，深色使用更亮的蓝色。
- 中文字体优先 PingFang、微软雅黑 UI；字重只用 400/500/600，取消标题负字距，避免微软雅黑把 550/650 渲染成过粗的粗体；有内容的文字不小于 12 px。
- 输入框改为白底（深色为内凹深底），单值字段统一宽度；下拉组件与原生下拉框外观一致；复选框与标签居中对齐。
- 侧栏行高更紧凑，子项与分组文字对齐；新增 OpenFi 菜单图标；分段页签使用系统填充色。
- 表头左对齐并去掉灰底横带；提示框与标题之间留出间距；进度条与工具栏指示更轻。
- 登录页改为标签在上、输入框通栏、按钮通栏，修复旧规则被通用表单样式覆盖的问题。
- 总览页统一字号与间距，DHCP 表头与内容对齐。

## 0.2.0-r5

- 将 nftables 防火墙规则状态页整理为规则链卡片，优化标题、策略说明与规则标签，适配浅色、深色和手机布局。

- 修复 PassWall 等旧版 CBI 表单的“保存”按钮白底白字，使用与外观匹配的次要按钮颜色。
- 原生状态概览在宽屏上采用两栏布局：左侧系统信息，右侧内存和存储；窄屏保留单栏。
- 两栏中的长固件版本和设备信息自动换行，保留 CPU 与进度条数值及原生轮询。

## 0.2.0-r4

首个公开发布版本，面向 OpenWrt / ImmortalWrt 24.10 的现代 LuCI。

- macOS 系统设置风格的侧栏、卡片、分段页签、表单和弹窗。
- 浅色、深色、自动外观与手机抽屉导航。
- 独立只读状态总览，包含 CPU、内存、流量、上行接口与 DHCP 租约。
- 修复原生 CPU 与进度条数值、页签截断、时间同步间距、手机表格溢出。
- 兼容插件多级页签和原生条件字段、验证提示。
- 完整版本资源缓存与软件包安装、升级、回退和卸载流程。
- 官方 OpenWrt 24.10.4 SDK 的 all 架构 `.ipk`，在 ImmortalWrt 测试机实际验证。

具体环境、对照主题和验证范围见 [检查记录](VALIDATION.md)。
